# HOI4 Agent Tools 4.11.1

Impassable walls in generated maps now close. A range with `barrier: "impassable"` is drawn as a barrier band, often 10 to 60 pixels wide, and province borders used to land anywhere inside it. So most province pairs on the wall got no impassable row, and province clean-up merged provinces across the wall at corners. Band pixels now go to the nearest province on their own side of the range path, so borders run along the path, and `MAP_RANGE_NOT_CLOSED` samples the provinces that meet there. On a large real map the two walls went from 49 of 79 and 186 of 193 sampled points open to fully closed.

`relief.painted` no longer fills a declared pass back up to the crest (`MAP_PASS_NOT_LOWER`): its raise is held to the pass saddle. A river whose last `via` lies next to its point mouth now reaches the mouth.

No schema changes, so this is a patch release.

```bash
npm install --global hoi4-agent-tools@4.11.1
hoi4-agent-tools-setup --print-client-config
```
