# HOI4 Agent Tools 3.7.0

One MCP server for finding local HOI4 rules, inspecting mod source, and previewing trees, interfaces, maps and event routes.

## Get started

Install Node.js 22.19+ in the Node 22 line, or Node.js 24, then run:

```bash
npm install --global hoi4-agent-tools@3.7.0
hoi4-agent-tools-setup --print-client-config
```

Add the printed configuration to your MCP client and open your mod as its workspace.
The [setup guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/main/docs/setup.md) covers game and mod paths.

## Work with focused context

Ask your agent to find a rule in installed documentation and the offline wiki, inspect the relevant block of a definition, or check an effect or trigger under its declared scope.
Source navigation handles repeated keys and nested array entries, with bounded pages and exact source citations.
The script checker reports unsupported or unresolved coverage and checks native command kinds and scopes; command parameters require their cited syntax.

The [README](https://github.com/klimPaskov/hoi4-agent-tools#examples) contains real visual examples and the full table of 35 tools.
The [reference guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/main/docs/reference.md) explains focused searches, source navigation, and command checks.

Source previews and declared scenarios provide offline evidence.
Native interactions, AI choices, transfer/timer behavior, and whole-image game accuracy require separate engine evidence.
