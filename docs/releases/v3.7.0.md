# HOI4 Agent Tools 3.7.0

HOI4 Agent Tools gives a coding agent one MCP server for Hearts of Iron IV modding.
It finds the installed game documentation and offline wiki sections a task needs, looks up exact definitions in the game, its DLC and your mod, previews focus trees, technology folders, interfaces, maps and event routes from source, and makes focused edits to focus trees, GUIs and maps.
Everything runs locally against your files; nothing starts the game.

## Get started

Install Node.js 22.19+ in the Node 22 line, or Node.js 24, then run:

```bash
npm install --global hoi4-agent-tools@3.7.0
hoi4-agent-tools-setup --print-client-config
```

Add the printed configuration to your MCP client and open your mod as its workspace.
The [setup guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/main/docs/setup.md) covers game and mod paths.
Every install receives the same reviewed dependency versions; npm fetches the image library's binaries for all platforms, about 280 MiB in total.

## Ask in plain words, get the exact entry

Documentation search understands questions such as "check if a state is controlled by a country" and finds `is_controlled_by`, weighing rare words above common ones and matching script names by their parts.
Individual wiki table entries for effects, triggers, modifiers and on actions are their own citations, and each result names the line that answers, so one short read lands on it.
On 61 held-out modding questions the answer-bearing section appeared within the first five results for 49, compared with 34 before.

## From a line to its definition

Pass a file and line, such as a diagnostic or a changed line in a diff, and the source lookup returns the definitions that contain it and the key path back to that exact block.
Lookups and previews include the installed DLC folders in the game's load order, so DLC sprites, portraits and interface layouts resolve, and a mod's own `replace_path` declarations apply as the game applies them.

## Checks that match the game's catalogs

Map validation reads the terrain categories and continent list, so unknown terrain, out-of-range continents, misplaced water terrain and invalid naval terrain are reported.
Adjacency rows after the file's terminator, which the game never reads, are flagged.
Script snippets can be checked for syntax, command kind and declared scope against the installed documentation, with unchecked parameters reported as such.

## See it
