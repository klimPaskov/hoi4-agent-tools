# HOI4 Agent Tools 4.21.0

This release makes idle servers small, fixes false findings in the GUI tools, and moves more analysis onto the shared Rust engine.

- **Idle servers stay small (issues 292 and 296).** A stdio server that is not called no longer loads or recovers any workspace. With a configuration holding several mods, its idle private memory dropped from 386 to 667 MB to about 108 MB in our measurements. Each workspace is found and its rewrite journal recovered on first use, before any file in it is read or written. A new setting, `idleCacheReleaseSeconds` (default 30), controls how long after the last call the in-memory analysis caches are released.
- **GUI fixes.**
  - `hoi4.gui_inspect` and `hoi4.gui_render` no longer report a sprite or font as unresolved when it belongs to another window in the same `.gui` file.
  - Engine placeholder texts such as `--` are no longer reported as missing localisation keys.
  - Masked flag shields now show the country's flag, not only the grey overlay.
- **More analysis on the Rust engine:**
  - the technology graph behind `hoi4.tech_inspect`;
  - map validation;
  - edit planning for the idea, character, decision, doctrine, technology and event writers;
  - the artifact store and diffs.

  Each one matches the TypeScript results on the tested corpora. The engine's rewrite journal and the event analysis are added too, but no tool uses them yet.

No tool changes its inputs or outputs. The server configuration gains one optional setting, `idleCacheReleaseSeconds`. Version 4.20.4 was never published, because its release check failed; its changes are in this release.

```bash
npm install --global hoi4-agent-tools@4.21.0
hoi4-agent-tools-setup --print-client-config
```
