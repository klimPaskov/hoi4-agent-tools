# HOI4 Agent Tools 4.17.0

This release fixes the world output record, `.hoi4-agent-world.json`, which 4.16.0 left incomplete. Map edits after `create_world` that created files (new `history/states/<id>-AGENT_STATE.txt` from `assign_territory`, `create_state` and merges) never added them to the record, and `record_world_outputs` dropped recorded bitmaps, colour maps and world scripts as gone because its scan did not read them. A copy of a mod synced from the record then loaded without those states and the game crashed. Every map edit now records the world outputs it creates in the same transaction, unread recorded files are kept, and `record_world_outputs` adds every world output the record does not list yet. One call repairs a mod written by 4.16.0:

```json
{ "operations": [{ "id": "adopt", "kind": "record_world_outputs" }] }
```

`hoi4.source_lookup` answers every lookup that names a symbol from the shared Rust engine, references included, and `hoi4.script_validate` gains `closure: true`: the references of the mod's own sources counted per kind as resolved, unresolved or unknown, with a verdict that is `incomplete` whenever anything is unknown. That finishes maintainer decision M-8. The map tools build the province raster on the engine, and event analysis hashes far less (event `graphHash` values are now version 3). Several tools answer inline instead of only counting: `hoi4.tech_inspect` explain names a technology's prerequisites, what it leads to and its unlocks; `hoi4.map_inspect` lists its matches; the probability tools accept a top-level `path`. Localisation values with quotes inside them are read as the game reads them.

The package ships the `hoi4-engine` binary for Windows x64, Linux x64, Linux arm64 and macOS on Apple silicon. The map tools now need it. On another platform, such as an Intel Mac, a tool that needs the engine answers `ENGINE_UNAVAILABLE` with the supported platforms and how to build the engine and point `HOI4_ENGINE` at it.

New options and output fields (`closure`, `adoptUnrecorded`, inline matches) make this a minor release.

```bash
npm install --global hoi4-agent-tools@4.17.0
hoi4-agent-tools-setup --print-client-config
```
