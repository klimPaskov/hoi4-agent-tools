# HOI4 Agent Tools 3.10.0

HOI4 Agent Tools gives a coding agent one MCP server for Hearts of Iron IV modding: local documentation and source lookup, previews of focus trees, technology folders, interfaces, maps and event routes, and focused edits to focus trees, GUIs and maps.

## Get started

Install Node.js 22.19+ in the Node 22 line, or Node.js 24, then run:

```bash
npm install --global hoi4-agent-tools@3.10.0
hoi4-agent-tools-setup --print-client-config
```

Add the printed configuration to your MCP client and open your mod as its workspace.
The [setup guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/main/docs/setup.md) covers game and mod paths.

## Faster repeat calls on large mods

After an edit, the server rebuilds its index from the previous one and parses only the files that changed.
It also keeps the latest scan of each pattern set and each interface graph instead of one per workspace, and its parse cache no longer churns when a scan is larger than the cache.
On a large mod that other agents were editing, a repeated interface preview took 64 seconds instead of 244.

## See every server on the machine

The `hoi4-agent://server/status` resource lists every server process that shares the server state root, with its memory, last client activity and the execution limits in effect.
The [setup guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/main/docs/setup.md#server-lifetime) describes it.

## Fixes

- A comparison without references fails at once when no earlier revision is cached, instead of after a full scan.
- A technology folder view without `folderId` returns a readable argument error.
- `proxy-addr` 2.0.8 fixes an IP spoofing advisory; the HTTP server configures no `trust proxy`, so earlier releases did not reach the affected code.
