# HOI4 Agent Tools 4.20.4

This release makes an idle stdio server small (issue 296).

An idle server no longer loads or recovers any workspace. The handshake and the tool list start nothing. The first request that needs a workspace finds the mods, and each workspace checks its rewrite journal once, on first use, before any file is read or written in it. With a configuration holding several mods, an idle server's private memory dropped from 386 to 667 MB to about 108 MB in our measurements, the same as a server with no configuration. A journal that cannot be recovered still blocks that workspace's rewrites with the same codes.

The release also carries the Rust rewrite engine (`hoi4-txn`), which no tool calls yet.

No tool changes its inputs or outputs.

```bash
npm install --global hoi4-agent-tools@4.20.4
hoi4-agent-tools-setup --print-client-config
```
