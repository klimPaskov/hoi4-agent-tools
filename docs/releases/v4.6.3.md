# HOI4 Agent Tools 4.6.3

This release fixes a world write that failed on a mod whose output inventory lists files the world does not manage. `.hoi4-agent-world.json` could record files that were never outputs of a generated world, such as country tag files or localisation files that the mod's own tooling registered, and one such entry made every write fail with `MANAGED_OUTPUT_MANIFEST_INVALID`. Those paths are now left alone: never read, compared, edited or deleted, dropped from the next inventory and reported as `MAP_WORLD_OUTPUT_RECORD_IGNORED`. A path that could leave the workspace, or a duplicate, still refuses the inventory.

```bash
npm install --global hoi4-agent-tools@4.6.3
hoi4-agent-tools-setup --print-client-config
```

No tool input or output schema changes. See the [changelog](https://github.com/klimPaskov/hoi4-agent-tools/blob/v4.6.3/CHANGELOG.md) and the [map guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/v4.6.3/docs/map.md).
