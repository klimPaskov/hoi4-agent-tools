# HOI4 Agent Tools 4.0.5

This patch fixes native panel composition in offline GUI previews. Centered windows keep their children at local coordinates. The division designer opens with one division/HQ branch and closed selector panels; scenario values can select the HQ view or a particular selector.

Dropdowns retain their expand button and expanded window as distinct controls. Closed panels hide their contents, while opened panels use their settled position, background, clipping and scrollbar. Scroll containers no longer require decorative backgrounds; explicitly disabled clipping and invalid viewport bounds still produce findings.

Engine-populated rows, statistics and conditional icons need scenario bindings. The preview conventions are documented in the fidelity report and do not claim live game state.

```bash
npm install --global hoi4-agent-tools@4.0.5
hoi4-agent-tools-setup --print-client-config
```

Public tool schema shapes and dependency versions are unchanged. See the [GUI guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/v4.0.5/docs/gui.md) for panel bindings and the [architecture decision](https://github.com/klimPaskov/hoi4-agent-tools/blob/v4.0.5/docs/adr/0051-native-panel-boundaries.md) for composition boundaries.
