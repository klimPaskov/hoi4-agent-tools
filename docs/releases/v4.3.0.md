# HOI4 Agent Tools 4.3.0

This release removes the last dependency on one particular game build. Probability analysis and decision AI weights now run on whatever HOI4 version is installed, including patches released after this version. The adapters apply the documented weighting rules of `ai_will_do`, `ai_chance`, mean time to happen, `random_list` and AI strategies; each result records the observed build as `workspace_verified`, `workspace_observed` or `version_unknown` instead of refusing with `PROBABILITY_GAME_VERSION_UNSUPPORTED`.

Event and focus analysis also read the installed game's `documentation/effects_documentation.md`. An effect that a later patch adds is recognized as native immediately, rather than being reported as a missing scripted helper until the built-in list is updated.

```bash
npm install --global hoi4-agent-tools@4.3.0
hoi4-agent-tools-setup --print-client-config
```

Tool input schemas are unchanged. Probability result metadata adds the `workspace_observed` and `version_unknown` statuses and an optional `reason`. See the [probability guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/v4.3.0/docs/probability.md).
