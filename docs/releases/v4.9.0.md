# HOI4 Agent Tools 4.9.0

Generated worlds can close the wrapping seam for fleets as well as armies (ADR 0061, amended). `create_world.edge.mode: "rim"` blocked land provinces across the seam, but the sea there stayed one connected sea, so ships sailed from the far west of a world to its far east. The new `edge.mode: "wall"` fills a ragged band at the east and west edges with land over the full height. The band is `rimPx` wide, 48 pixels by default. Its provinces become impassable `enclave` states, linked by `force_link_ownership_to` to the nearest passable state, as the base game's impassable states are, and impassable rows block every land pair across the seam. The wall takes the look of the land it meets, row by row, or follows caller `wallTerrain` segments. Cities and workspace capitals inside the wall are refused, and validation reports water on the seam columns of a wall world as `MAP_EDGE_WALL_OPEN`. `polarPx: 0` lets drawn land run off the top and bottom edges.

Three new read-only tools run on the shared Rust engine: `hoi4.system_inspect` (`hoi4-engine system`) reads on_actions, military-industrial organizations, balances of power, special projects, operations and raids; `hoi4.unit_inspect` (`hoi4-engine units`) reads orders of battle, sub-units, equipment and equipment variants; and `hoi4.asset_inspect` (`hoi4-engine assets`) reads sprites, sounds and flags. `hoi4.script_validate` now checks that the ideas, decisions, focuses, technologies and events an effect or trigger names are defined by the mod, its dependencies or the game. Inspect tools now apply every selector they are given and answer an id that nothing defines with an explicit not-found error and close names, instead of `ok` with an empty result.

How the engine draws a full-height wall and how fleets path along an impassable coast are not yet verified in the game.

The map operation schema gains an enum value and an optional field, and three tools are added, so this is a minor release.

```bash
npm install --global hoi4-agent-tools@4.9.0
hoi4-agent-tools-setup --print-client-config
```
