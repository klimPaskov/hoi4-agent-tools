# HOI4 Agent Tools 4.7.0

Focus trees get a layout verdict (ADR 0075). `hoi4.focus_inspect`, `hoi4.focus_render` and `hoi4.focus_rewrite` return `layoutQuality`: a verdict of `pass`, `review`, `revise` or `blocked`, with the places to fix. Crossings, connectors through plaques and shared bars are now counted in the in-game right-angle connector model. A compact reflow is accepted only when it is no worse than the layout in place. `hoi4.focus_render` also returns an in-game-style overview and up to five close-ups as inline images.

Documentation search finds more answers from plain-word questions (ADR 0076): command entries also match the words of their in-game tooltip or modifier name. The reference tools read the kit's wiki from `hoi4_wiki/` in a mod, falling back to the older `paradox_wiki/` for a mod the kit has not updated; `hoi4_wiki/` wins when both exist.

The focus plan schema changes (new layout fields), so this is a minor release. Three transitive dependencies are raised to their fixed releases, clearing every `npm audit --omit=dev` advisory.

```bash
npm install --global hoi4-agent-tools@4.7.0
hoi4-agent-tools-setup --print-client-config
```
