# HOI4 Agent Tools 4.12.0

The stdio server connects faster. It used to re-check every retained rewrite journal before it answered `initialize`, and each applied `create_world` leaves a journal of about 7 MB, so a mod with many map writes took 4 to 8 seconds to connect and clients with a 30-second limit gave up under load. The server now answers the handshake at once (about 1.1 seconds on a configuration with 28 MB of map journals) and recovers in the background. Tool calls wait until recovery ends, so no call reads or writes a workspace before an interrupted rewrite is recovered.

A `create_world` preview with `synthesisCheck: true` now lists every blocking problem it can find in one answer: realm points that cannot be placed, cities and capitals on impassable land, rivers that cannot reach their mouths, and passes that are not lower than their crest. Before, the check stopped at its first error, and cities and capitals on impassable land showed up only in a write. Leaks through a wall still need the partition, so only a write reports them.

`create_world.inheritedContinents: "drop"` writes only the generated continents, so a total conversion no longer shows the base game's continents, and every script reference to a dropped continent is reported with its file and line. Impassable land no longer joins landmasses, strategic regions or countries: a wall at the map's edge no longer makes one continent across the seam, and realms grow over passable land only.

`hoi4.mod_index` runs on the shared Rust engine, with the same answers and a cold call 2 to 10 times faster on large mods. The probability adapters are pinned to game 1.19.4.2.

The two ChaosX tools are no longer in the public package. The stdio server loads plugins from the absolute paths listed in the new configuration key `plugins` instead; a plugin's tools are named `<plugin>.<tool>`, and the HTTP server never loads one.

The release workflow now authenticates its publication checks and waits up to 20 minutes for npm.

New options and a new configuration key make this a minor release. A client that set `HOI4_AGENT_TOOLS_CHAOSX` must list the plugin under `plugins` instead.

```bash
npm install --global hoi4-agent-tools@4.12.0
hoi4-agent-tools-setup --print-client-config
```
