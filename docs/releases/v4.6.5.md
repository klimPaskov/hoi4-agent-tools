# HOI4 Agent Tools 4.6.5

A map rewrite's inline result lists only a bounded number of changed files, so the result of writing a whole world, thousands of files, could look as if almost nothing changed. Every applied map rewrite now also returns `data.changedSummary`: how many files were changed, created, removed and modified, in total and for the 40 folders with the most changes.

```bash
npm install --global hoi4-agent-tools@4.6.5
hoi4-agent-tools-setup --print-client-config
```

The output gains one optional data field; no tool input schema changes. See the [changelog](https://github.com/klimPaskov/hoi4-agent-tools/blob/v4.6.5/CHANGELOG.md).
