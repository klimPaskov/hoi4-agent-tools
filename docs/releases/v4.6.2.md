# HOI4 Agent Tools 4.6.2

This release makes countries that a mod already owns easier to place. `create_world` with `countries.source: "workspace"` now checks every capital and seed before it builds the relief or the provinces, and reports all problems in one error: points outside the world or in water (with the nearest land and its distance), in the unowned area, an own exclusion or another realm's claim, and points of different realms closer than 10 pixels. `create_world.synthesisCheck` runs the same check and lists the points beside the rivers that cannot reach their mouths, so one preview shows everything a write would stop on. In the feature-aware partition each capital and seed is the centre of a province of its own, so capitals only 10 to 40 pixels apart each get a province and a state instead of failing the world.

```bash
npm install --global hoi4-agent-tools@4.6.2
hoi4-agent-tools-setup --print-client-config
```

No tool input fields are added; the `capital` and `seeds` descriptions now state the 10-pixel separation. A feature-aware world with workspace countries gets a slightly different province partition; other worlds are unchanged. See the [changelog](https://github.com/klimPaskov/hoi4-agent-tools/blob/v4.6.2/CHANGELOG.md) and the [map guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/v4.6.2/docs/map.md).
