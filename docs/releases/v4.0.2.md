# HOI4 Agent Tools 4.0.2

This documentation patch updates the npm and GitHub README with the supplied HOI4 MCP Server thumbnail. Click it to watch the [demo video](https://www.youtube.com/watch?v=Dd36E_NK4rQ).

The thumbnail uses a public image URL so it loads on the npm package page. Server behavior, tool schemas and dependency versions are unchanged from 4.0.1. The qualification and limitations documented in [4.0.1](v4.0.1.md) still apply.

4.0.1 remains the latest marked GitHub release; older releases are retained. npm requires a new package version to refresh its README, so the updated npm package is 4.0.2.
