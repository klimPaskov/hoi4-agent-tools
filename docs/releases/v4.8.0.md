# HOI4 Agent Tools 4.8.0

The package now ships `hoi4-engine`, the shared Rust engine (ADR 0074, amended). The release builds it for Windows x64, macOS arm64 and Linux x64 and arm64 (glibc 2.35 or later) and bundles every platform under `engine/bin/` with a SHA-256 manifest; the server runs the bundled binary only after its checksum matches. The container image carries the binary for its own architecture. `HOI4_ENGINE` still overrides the bundled binary. One engine process now stays up for the server's life (ADR 0077), and the focus preview draws the in-game national focus view through it instead of rasterizing the schematic SVG, which took about two minutes per call on vanilla Germany.

Two new read-only tools run on the engine: `hoi4.localisation_inspect` reads every localisation file of the game, DLC, dependencies and mod in every language, and `hoi4.idea_inspect` returns an idea with its category, every definition in load order, its picture and its modifiers checked against the game's documentation. `hoi4-engine check` reports duplicate ids of every definition kind.

Accuracy fixes from the benchmark sweeps (`bench/`, `npm run bench`): `hoi4.script_validate` no longer raises 104 of the 110 false errors it found on known-good vanilla and large-mod files. `hoi4.gui_inspect`, `hoi4.event_inspect`, `hoi4.source_lookup` and `hoi4.decision_inspect` no longer return an empty `ok` for something that does not exist, and they no longer flag working GUI or scripted effects as unresolved. `hoi4.error_log` checks that the logged launch loaded the mod. Documentation search also matches plain-word phrasings of each effect, trigger and modifier (ADR 0078). All DDS formats the game draws are decoded.

New tools and new inputs make this a minor release.

```bash
npm install --global hoi4-agent-tools@4.8.0
hoi4-agent-tools-setup --print-client-config
```
