# HOI4 Agent Tools 4.0.0

Build and edit Hearts of Iron IV mods with your coding agent. Make focus trees, events and decisions, create worlds from drawings, preview trees, windows and maps, fix script errors and balance AI choices.

## Get started

Install Node.js 22 (22.19 or later) or Node.js 24, then run:

```bash
npm install --global hoi4-agent-tools@4.0.0
hoi4-agent-tools-setup --print-client-config
```

Paste the printed `globalInstall` block into a JSON client such as Claude Code, Claude Desktop or Cursor, or `codexTomlGlobal` into Codex. Open your mod as the agent's workspace and tell it what to build or fix.
The agent picks the tools it needs. The [setup guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/main/docs/setup.md) covers multiple mods, paths and troubleshooting.

## Build and reshape worlds

Create a world from land outlines or a seed and country descriptions. Generate provinces, states, terrain, rivers, country files, flags, building positions and supply networks, then refine the map.
Split or merge states, move provinces and update the events, focuses and decisions that refer to them. Dated state history is supported, and building levels stay whole.
Moving provinces redistributes their share of manpower, resources and slot buildings by default; use `stateValues: "retain-in-current-states"` to keep the previous values.

## Fix broken script

Find documented scripting mistakes with explanations and fixes. Read errors from the last game launch, grouped by category and linked to their source files. After a relaunch, see which errors appeared and which your edits removed.

## Understand AI choices

Find AI weights, event timing and random lists and evaluate them in the same call. Compare a proposed edit, explore the conditions that change the strongest choice and identify missing facts.

## Work across a mod

Preview focus trees, technology folders, windows, maps and event routes. Find the right rule in the game docs and wiki, locate vanilla examples and follow references between files.
Tools accept common shorthand arguments. Errors name the field that needs attention and include a working call. Repeated renders reuse loaded indexes.

## Integration changes

- `hoi4.probability_evaluate`, `_sweep`, `_simulate`, `_sequence`, `_compare` and `_render` are covered by `hoi4.probability_inspect` and `hoi4.probability_analyze`.
- Event and technology comparisons use `mode: compare`. `hoi4.focus_raster` is covered by `hoi4.focus_render`, and `hoi4.map_render` by `hoi4.map_inspect`.
- An unauthenticated HTTP `POST /mcp` returns `401` before its body is parsed.
- `TRANSACTION_RECOVERY_REQUIRED` identifies a workspace whose interrupted rewrite needs recovery. Other workspaces remain available; see [troubleshooting](https://github.com/klimPaskov/hoi4-agent-tools/blob/main/docs/troubleshooting.md).
- `tools/list` omits the JSON Schema dialect and repeated integer bounds.

See the [configuration reference](https://github.com/klimPaskov/hoi4-agent-tools/blob/main/docs/configuration.md) for settings and the [changelog](https://github.com/klimPaskov/hoi4-agent-tools/blob/main/CHANGELOG.md) for the complete technical changes.
