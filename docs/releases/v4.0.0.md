# HOI4 Agent Tools 4.0.0

HOI4 Agent Tools is an MCP server that lets a coding agent read, preview, analyse and safely edit a Hearts of Iron IV mod: cited answers from local documentation, previews of focus trees, technology folders, interfaces, maps and event routes, AI-weight analysis, and validated edits to focus trees, GUIs and maps.

## Get started

Install Node.js 22 (22.19 or later) or Node.js 24, then run:

```bash
npm install --global hoi4-agent-tools@4.0.0
hoi4-agent-tools-setup --print-client-config
```

Paste the printed `globalInstall` block into a JSON client such as Claude Code, Claude Desktop or Cursor, or `codexTomlGlobal` into Codex, and open your mod as the agent's workspace.
The [setup guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/main/docs/setup.md) covers several mods, explicit paths and troubleshooting.

## Fewer tools that answer more

The server has 28 tools instead of 37: one inspect tool per domain, with comparisons and renders as modes of it.
`hoi4.probability_inspect` finds an AI weight, MTTH or random list and evaluates it in the same call, ranking the candidates inline with the facts still missing.
Tools accept the shorthands agents send most often, such as an event ID string as a selector or a scenario without an ID, and answer with the mod's own files and findings first.
A call that is still wrong comes back as an error the agent can read, naming the field, what it expected and a working call.
Job workers stay warm between calls, so a second render or inspection of a large mod reuses the indexes the first one loaded.

## Reshape a map, or build a new one

`hoi4.map_rewrite` creates a complete new world from a seed and a list of countries, places building, unit and weather positions and the supply network from geometry, and rewrites the events, focuses and decisions that name split or merged states.
States with dated history can be split, and building levels stay whole.
`hoi4.map_inspect` with `references: true` lists every script reference to a state, province or region the map lacks.
Ask your agent: "Split Brandenburg in two and update every event and focus that names it."

## Read the game's error log

`hoi4.error_log` reads the `error.log` the game wrote at its last launch and groups it by category: syntax, duplicates, localisation, effects, triggers, scopes, graphics, interface, map and missing references.
Each entry names its source file, line and layer, says whether that file changed after the log was written, and mod entries come first.
After a relaunch it says which errors are new and which your fixes removed.
Ask your agent: "Group the last error.log by category and fix the scope errors in my files."

## Index the mod and pick free IDs

`hoi4.mod_index` summarizes a mod's descriptor, how many events, focuses, decisions and other definitions it has, its folders and its event namespaces with their number ranges.
It also finds the next free numbered ID for an event namespace or prefix, checked against the game, DLC and dependencies as well as the mod.

## Steadier servers and safer rewrites

- An incremental index rebuild keeps each file's own diagnostics.
- A cancelled request no longer keeps an idle stdio server alive, and an orphaned worker that reaches its deadline settles its job.
- A damaged rewrite journal blocks only its own workspace, with the reason, instead of stopping the server.
- Rewrites re-check their journal under the workspace lock, re-hash the backup they move aside, and take over a crashed lock only through an atomic rename.
- The HTTP server authenticates a request before reading its body and rate-limits by the last untrusted forwarded address.

## Breaking changes

- `hoi4.probability_evaluate`, `_sweep`, `_simulate`, `_sequence`, `_compare` and `_render`, `hoi4.event_compare`, `hoi4.tech_compare`, `hoi4.focus_raster` and `hoi4.map_render` are folded into `hoi4.probability_inspect`, `hoi4.probability_analyze`, `mode: compare`, `hoi4.focus_render` and `hoi4.map_inspect`.

- An unauthenticated HTTP `POST /mcp` receives `401` before its body is parsed.
- A rewrite journal that cannot be recovered reports `TRANSACTION_RECOVERY_REQUIRED` on rewrites of its workspace instead of failing startup.
- `tools/list` omits the JSON Schema dialect and repeated safe-integer bounds.
