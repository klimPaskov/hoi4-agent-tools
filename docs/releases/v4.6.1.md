# HOI4 Agent Tools 4.6.1

This release fixes two false results. A pass that a geography model declares is now always a saddle lower than the crest on both sides: a volcano cone, plateau or neighbouring feature that overlaps the pass no longer fills the gap and fails the world with `MAP_PASS_NOT_LOWER`, and `create_world.synthesisCheck` now reports that error too, so a preview shows what the write would block on. The script validator no longer reports `constant:<category>.<key>` script-constant reads as scoped temporary-variable reads.

```bash
npm install --global hoi4-agent-tools@4.6.1
hoi4-agent-tools-setup --print-client-config
```

No tool input or output schema changes. Models whose passes were refused now write; the relief of a model whose passes overlap other relief changes inside the pass corridor. See the [changelog](https://github.com/klimPaskov/hoi4-agent-tools/blob/v4.6.1/CHANGELOG.md) and the [map guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/v4.6.1/docs/map.md).
