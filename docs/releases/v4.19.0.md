# HOI4 Agent Tools 4.19.0

This release adds writers for the definitions a mod edits most often. Each one adds, replaces or removes a single block in a mod file and leaves every other byte of the file as it was: comments, neighbouring blocks, newline style and encoding.

New tools:

- `hoi4.idea_write` for ideas, national spirits, laws and advisors. It can also create a missing category or a new ideas file.
- `hoi4.character_write` for characters.
- `hoi4.event_write` for events. With `chain: true` it also reports what the edit does to the event chains.
- `hoi4.decision_write` for decisions.
- `hoi4.tech_write` for technologies. With `placement: true` it also reports which technologies the edit adds, removes or moves on the tree.
- `hoi4.doctrine_write` for grand doctrines, tracks and subdoctrines.

The preview of every one of these shows the change in hunks with three lines of context, not the whole file.

Faster focus work. A focus edit can answer as soon as it is durably written (`answerBeforeCheck: true`) and run its after-edit check as a job. The sprite graph of the focus icons, the installed game's file list and the symbol index are reused between calls while the files are unchanged, and a rewrite no longer slows down with every earlier rewrite of the session. A small edit followed by an inspect now takes about two seconds instead of 20 to 90 seconds. Getting under one second is the next step.

The shared symbol index is now built by the Rust engine, and the old TypeScript index is gone. The events, technology, decisions, focus, GUI, impact, package check, mechanics and scenario tools read from it. `hoi4.mod_health` checks large mods much faster: on Old World Blues it went from 38 to 18 seconds and now checks about 400 script files instead of 37.

Checks and previews:

- The GUI tools report keys the game refuses at load, draw an `iconType` at its sprite's size, and say why a texture behind a linked folder is not found.
- A strategic region of exactly two provinces that do not touch is reported as a warning.
- Map writes give the states they create or reshape their building positions.
- `hoi4.script_validate` reports a parser warning as a warning, not an error.
- The probability tools say whether the installed game is the build their rules were checked against, and now cover game 1.19.5.0.
- A rewrite that waits for another rewrite's lock no longer fails with `ENOENT`.
- Event comparison on a large graph now finishes.

It is a minor version because it adds tools and optional inputs.

```bash
npm install --global hoi4-agent-tools@4.19.0
hoi4-agent-tools-setup --print-client-config
```
