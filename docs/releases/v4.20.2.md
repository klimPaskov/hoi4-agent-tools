# HOI4 Agent Tools 4.20.2

This release fixes a regression in 4.20.1. On a mod with `localisation/replace/` files in many languages, `hoi4.gui_inspect` and `hoi4.gui_render` refused with `GUI_LOCALISATION_BUDGET_BLOCKED`. 4.20.1 read the replace files of every language, so they could fill the 500,000-candidate ceiling. The GUI scan now reads only the replace files of the preview's languages. The ceiling is unchanged.

No tool changes its inputs or outputs.

```bash
npm install --global hoi4-agent-tools@4.20.2
hoi4-agent-tools-setup --print-client-config
```

See the [changelog](https://github.com/klimPaskov/hoi4-agent-tools/blob/v4.20.2/CHANGELOG.md).
