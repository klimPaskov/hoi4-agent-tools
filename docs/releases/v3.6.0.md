# HOI4 Agent Tools 3.6.0

Give your coding agent one MCP server for Hearts of Iron IV modding. Point it at a mod and an installed copy of the game to find relevant rules, trace content through source files, and preview focus trees, technology folders and interfaces with their real artwork.

## Get started

Install Node.js 22.19+ in the Node 22 line, or Node.js 24, then run:

```bash
npm install --global hoi4-agent-tools@3.6.0
hoi4-agent-tools-setup --print-client-config
```

Add the printed configuration to your MCP client and open your mod as its workspace. The [setup guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/main/docs/setup.md) covers game and mod paths.

## See what it can show

The [README](https://github.com/klimPaskov/hoi4-agent-tools#examples) has the complete gallery and all 34 public tools. It shows Fury, Holy Realm and Utopia Manifesto focus trees; infantry, chemical and biological technology folders; vanilla and Chaos Redux interfaces; a source map; and an event chain. Supplied game screenshots appear beside MCP previews where available.

Try asking your agent to find the installed documentation for `save_event_target_as` and a vanilla usage, show Fury's alternative focus prerequisites, or render an interface at two UI scales and check its text and controls.

The server can inspect and render without changing the mod. Its focus, GUI and map rewrite tools can apply a specific reviewed source edit. Preview states and source calculations describe declared inputs; native clicks, AI choices, timer behavior and whole-image game accuracy still need separate game evidence.
