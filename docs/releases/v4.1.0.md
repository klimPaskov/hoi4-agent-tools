# HOI4 Agent Tools 4.1.0

Give the MCP server a reference image inside the authorized mod workspace:

```json
{
  "operations": [{ "kind": "create_world", "reference": { "imagePath": "references/world.png" } }]
}
```

The server supplies dimensions, countries and map-generation defaults. Add top-level `preview: true` to inspect offline reference, terrain and political comparison images without writing the mod. Repeat without that flag to apply the internally validated rewrite.

The [map guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/v4.1.0/docs/map.md#generate-a-world-from-one-image) explains optional layers, biome masks, reviewed names, ambiguity warnings and existing refinement operations. The additive image contract and preview response require a minor version, rather than a 4.0.x patch. Existing procedural requests retain their defaults.

Reference inputs stay local and read-only. Their original hashes participate in normal stale-source checks. OCR uses packaged English data without runtime network downloads. Handwriting, decorative artwork and unmarked political boundaries remain uncertain; the server reports assumptions instead of claiming that every label is understood.

CI fixtures are original synthetic maps. Offline previews do not prove game loading or campaign behavior; see the [separate live evaluation report](https://github.com/klimPaskov/hoi4-agent-tools/blob/v4.1.0/docs/evaluations/worldgen_acceptance_2026-10-15.md) for measured acceptance and remaining issues.

Reference worlds include a provisional starting scenario and safely retire obsolete generated files on rebuild. Edited generated files block replacement. Use a clean reference without handwriting, legends or paper seams, then inspect its terrain preview before writing.

```bash
npm install --global hoi4-agent-tools@4.1.0
hoi4-agent-tools-setup --print-client-config
```
