# HOI4 Agent Tools 4.13.0

The stdio server now lists only the 13 core tools by default: documentation search and reading, source lookup, script validation, the invented-command guard, the error log and its explanations, the mod health check, the mod index, localisation and kit skills. That cuts the tool list every session loads from about 90 KB to 24 KB. The `map` profile adds the world map tools, and `advanced` adds the focus, GUI, event, technology, decision and probability editors and the other inspect tools. Set `HOI4_AGENT_TOOLS_PROFILES` (for example `core,map` or `all`) in the client registration, or the new `profiles` configuration key, to list more. A tool outside the listed profiles still answers a call. The HTTP server and servers built in code still list every tool.

Five new tools: `hoi4.script_guard` reports invented effects, triggers and modifiers in recently written files, with the closest real name. `hoi4.explain_error` explains `error.log` lines with the rule, the fix and the source lines. `hoi4.mod_health` gives a one-call health report. `hoi4.localisation_write` adds keys and fixes localisation files atomically and returns the diff. `hoi4.compat_check` compares a mod with another mod or with a game update. `hoi4-agent-tools-setup --fetch-docs` installs a pinned documentation pack, so the reference tools answer with no mod open.

`create_world` no longer writes adjacency rows across the wrapping seam for `wall` and `rim` worlds. The game drew each of them as a line through the whole map. Land on the first and last column becomes impassable states instead, and validation reports any row between provinces that touch only across the seam as `MAP_ADJACENCY_ACROSS_SEAM`.

The core-profile default changes what a stdio client lists, and five tools are new, so this is a minor release. A client that needs every tool on stdio sets `HOI4_AGENT_TOOLS_PROFILES=all`.

```bash
npm install --global hoi4-agent-tools@4.13.0
hoi4-agent-tools-setup --print-client-config
```
