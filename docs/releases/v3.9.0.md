# HOI4 Agent Tools 3.9.0

HOI4 Agent Tools gives a coding agent one MCP server for Hearts of Iron IV modding: local documentation and source lookup, previews of focus trees, technology folders, interfaces, maps and event routes, and focused edits to focus trees, GUIs and maps.

## Get started

Install Node.js 22.19+ in the Node 22 line, or Node.js 24, then run:

```bash
npm install --global hoi4-agent-tools@3.9.0
hoi4-agent-tools-setup --print-client-config
```

Add the printed configuration to your MCP client and open your mod as its workspace.
The [setup guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/main/docs/setup.md) covers game and mod paths.

## Servers end when nobody can reach them

A stdio server exits when the process that launched it has exited.
Clients that start a server for every subagent and keep each connection open can set `HOI4_AGENT_STDIO_IDLE_EXIT_MINUTES` in their registration, and the printed Codex registrations set it to 30, so idle servers no longer pile up.
Read-only background jobs stop at `jobDeadlineSeconds`, even when their server has gone, and a job that ignores cancellation is stopped after `jobCancelGraceSeconds`.
The [setup guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/main/docs/setup.md#server-lifetime) explains the settings.

## Check a whole script file before launching the game

`hoi4.script_validate` with a `path` checks every effect and trigger body of an event, decision, focus, scripted helper or on-action file under the scope its structure fixes.
It reports dynamic variables compared as triggers, scope links outside their scopes, colour codes in news and report events, development wording in shown text, unlocalised flags in requirement tooltips, and events that reach one player once per loop iteration.
The [reference guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/main/docs/reference.md#check-a-whole-file) lists every check.

## Interface previews match the selected page

GUI scenarios publish their shape, and `closedFlags: true` treats undeclared flags as unset, so tabbed windows render one page at a time.
Scripted localisation resolves wherever the scenario decides its branch, overlapping elements the scenario leaves undecided are named, and elements a few pixels off centre are flagged.
`background: "transparent"` renders without the preview backdrop for compositing.
The [GUI guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/main/docs/gui.md#scenario-fields) describes the scenario fields.
