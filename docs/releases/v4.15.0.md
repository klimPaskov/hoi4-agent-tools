# HOI4 Agent Tools 4.15.0

`create_world.synthesisCheck` now estimates the permanent-snow share the write will have. Until now only the write reported `MAP_PERMANENT_SNOW_SHARE`, so trying `permanentSnow` thresholds took a full write each time. The check applies the write's rule to the half-resolution relief it already builds. It reports `MAP_PERMANENT_SNOW_ESTIMATE` with the same details, also under `synthesisCheck.permanentSnow`. On a 1,024 by 512 test world the estimate was within 1% of the share the write reported.

`hoi4.source_lookup` answers from the shared Rust engine when a call asks for no references (`includeReferences: false`), as `hoi4.mod_index` already does (ADR 0082). On the installed game a cold event lookup of that kind takes 61 ms instead of about 2 seconds. A lookup with references, which is the default, and a lookup by file and line still use the TypeScript scan.

The new diagnostic and result field make this a minor release. No input schema changed.

```bash
npm install --global hoi4-agent-tools@4.15.0
hoi4-agent-tools-setup --print-client-config
```
