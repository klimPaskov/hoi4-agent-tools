# HOI4 Agent Tools 4.14.0

`create_world` no longer turns land drawn as snow into permanent snow, which the game draws as bright blue ice. Drawn snow is now ordinary land with seasonal snow, as the base game's northern lands are, and a strategic region drawn mostly as snow gets winters with snow. Permanent snow stays on ice caps in the tenth of rows nearest each pole, on drawn snow at height 150 and up, and above the snow lines of ranges and painted mountains. `MAP_PERMANENT_SNOW_SHARE` reports the permanent-snow share of the land against the base game's 0.76%, and warns above four times that share.

The new `create_world.permanentSnow` option moves the two thresholds (`{ iceCapLatitude, peakHeight }`), or with `"snowlines"` keeps permanent snow only above the snow lines. A world whose inhabited north reaches the top rows, or one with painted relief, needs higher values: on a 5,120 by 2,560 world with 29% of its land drawn as snow, `0.97` and `230` left 0.9% permanent snow, and the defaults 9.5%.

The new optional field makes this a minor release. Requests that use no drawn snow get the same output as before, except that snow lines in a reference world now use the base game's snowy mountain entry (16) instead of 19.

```bash
npm install --global hoi4-agent-tools@4.14.0
hoi4-agent-tools-setup --print-client-config
```
