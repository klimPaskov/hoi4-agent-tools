# HOI4 Agent Tools 4.6.4

This release lets a large world be written. The check after a map write read every changed file again, bitmaps and textures included, together with the base game's files of the same names. For a 5120 x 2560 world that is about 270 MB, more than the default scan limit of 256 MiB, so the write was restored after seven minutes. The check now reads the changed text files only, and the map validation that follows reads the bitmaps it needs within the limit.

When a rewrite is restored because of a scan limit, the message now names the file, the bytes read and the limit, and a file larger than `scanMaxFileBytes` stops the rewrite before anything is written.

```bash
npm install --global hoi4-agent-tools@4.6.4
hoi4-agent-tools-setup --print-client-config
```

No tool input or output schema changes. See the [changelog](https://github.com/klimPaskov/hoi4-agent-tools/blob/v4.6.4/CHANGELOG.md).
