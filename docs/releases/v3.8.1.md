# HOI4 Agent Tools 3.8.1

HOI4 Agent Tools gives a coding agent one MCP server for Hearts of Iron IV modding: local documentation and source lookup, previews of focus trees, technology folders, interfaces, maps and event routes, and focused edits to focus trees, GUIs and maps.

## Get started

Install Node.js 22.19+ in the Node 22 line, or Node.js 24, then run:

```bash
npm install --global hoi4-agent-tools@3.8.1
hoi4-agent-tools-setup --print-client-config
```

Add the printed configuration to your MCP client and open your mod as its workspace.
The [setup guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/main/docs/setup.md) covers game and mod paths.

## Upgrading keeps working

Installed DLC folders are source layers, so a workspace's roots differ from those recorded by earlier versions.
Finished rewrite records from before that change no longer stop the server from starting; they simply expire.
An interrupted rewrite recorded under different roots is still refused rather than replayed.

Everything else matches 3.8.0: plain-word documentation search with exact table-entry citations, line-to-definition lookup, DLC-aware lookups and previews, and map catalog checks.
The [README](https://github.com/klimPaskov/hoi4-agent-tools#examples) shows real previews beside supplied in-game captures and lists all 35 tools.
