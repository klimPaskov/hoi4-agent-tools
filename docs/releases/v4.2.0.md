# HOI4 Agent Tools 4.2.0

This release makes the event-chain, decision and impact tools dependable on large mods. Every event inspection mode, including workspace-wide `scan`, `lint`, `state_flow`, `impact` and unselected overview renders, now completes on a mod with thousands of events instead of failing with string-length, work-ceiling or raster-budget errors. Job workers keep running when a mod folder is removed after the server starts.

Event inspections answer inline. `data.summary` lists finding counts by classification, code and layer with the ten most severe source-linked findings, the mod's own files first; traces, paths, roots and impact report their size and reach.

Many false findings are gone. `event_target:name` reads see global targets, temporary-variable and helper-scope writes satisfy reads, native effect arguments and condition blocks are no longer mistaken for missing scripted helpers, and each recursive helper loop is reported once. Decision scenarios treat undeclared variables and event targets as unknown, and keep their gate and cost evidence when the installed game version is not verified for AI-weight adapters.

```bash
npm install --global hoi4-agent-tools@4.2.0
hoi4-agent-tools-setup --print-client-config
```

Tool input schemas are unchanged. Output adds the optional `summary` to event inspection, `omittedBranchRenders` to event renders and `affectedFilePaths` to impact results; impact no longer lists affected files in `changedFiles`. See the [event guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/v4.2.0/docs/events.md) and the [analysis guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/v4.2.0/docs/analysis.md).
