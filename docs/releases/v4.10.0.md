# HOI4 Agent Tools 4.10.0

Generated worlds can follow a drawn map's mountains and wall land off (ADR 0079). `create_world.relief.painted` raises the relief toward a reference picture's painted mountain, hills and volcano classes before the rivers are routed. The classes are blurred over `falloffPx`, so the slopes stay natural, the model's rivers flow around the drawn ranges, and painted mountains get permanent snow by latitude. Land painted with the new palette kind `impassable_mountain`, or inside a geography region marked `impassable: true`, becomes impassable `enclave` states linked to the nearest passable state, as the base game writes its impassable states. It rises to the highest ground, and cities and capitals on it are refused (`MAP_FEATURE_IN_IMPASSABLE`). `MAP_REALM_CUT_OFF` and `MAP_REALM_ENCLOSED` warn when impassable land or borders cut a realm apart or box it in. `MAP_RELIEF_SYNTHESIZED` now reports the base game's relief beside the world's.

`create_world.partitionTuning.lakeArea` sets the size of a lake province (default 6,000 pixels), so a large drawn lake can stay one province.

`script_validate` no longer reports guarded and presence reads of event targets as reads before a save (#60). The hand-kept game data is checked against the installed build (#70).

Passes cut as corridors through impassable land are not done yet; a pass still opens a range line only. How the game draws and paths around impassable land from these worlds is not yet verified in the game.

The map operation schema gains an enum value and optional fields, so this is a minor release.

```bash
npm install --global hoi4-agent-tools@4.10.0
hoi4-agent-tools-setup --print-client-config
```
