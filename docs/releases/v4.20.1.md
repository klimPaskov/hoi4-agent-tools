# HOI4 Agent Tools 4.20.1

This release fixes renders of scripted GUIs that disagreed with the game, and cleans up after a refused rollback.

GUI renders:

- `hoi4.gui_render` and `hoi4.gui_inspect` now read a mod's `localisation/replace/` folder. A window showed the base game's text, such as "Trade" or "Production", where the mod replaces it.
- A text box's `text_color_code` now sets the colour of its text, looked up like in-text `§` codes.
- Each texture is written into the SVG once and drawn by reference. One large nine-slice texture shared by a few dozen elements could reach the artifact ceiling (`ARTIFACT_LOGICAL_BATCH_LIMIT`).

Refused rollbacks. When another writer changes a target during an apply, the automatic rollback is still refused, as before. The files still holding the written bytes now lose their `.backup` copies, and their before-bytes stay in the journal. The refusal names the conflicting files that keep one. An expired failed journal is reclaimed once the workspace holds all of its written bytes.

Also in this release:

- `hoi4.event_inspect`'s `explain_path` now finds paths through scripted-effect helpers (issue 278).
- Canonical path checks move to the shared Rust engine, with no change in results.
- More groundwork for the Rust port.

No tool changes its inputs or outputs, so this is a patch version.

```bash
npm install --global hoi4-agent-tools@4.20.1
hoi4-agent-tools-setup --print-client-config
```
