# HOI4 Agent Tools 4.5.0

This release lets a mod that owns its countries generate or import a map that carries them. `create_world.countries` accepts `{ "source": "workspace", "realms": [...] }`: each realm is a tag the mod already declares, with a capital point and optional seeds, claimed and excluded areas and a weight; `unowned` areas and an island rule decide land nobody claims. The world then writes only the map, states, strategic regions and their names, and none of the countries' tag files, country files, histories, orders of battle, flags, names or bookmark.

Every world write now reports what it does to the previous world's files: how many it writes, which earlier outputs it retires and which edited country files it releases to the mod instead of refusing the write. It also reports the number of declared country tags and warns above 439, the count at which one measured game build overflowed its flag sheet.

```bash
npm install --global hoi4-agent-tools@4.5.0
hoi4-agent-tools-setup --print-client-config
```

The `create_world.countries` input becomes a union of the existing array and the new object; requests with the array are unchanged, byte for byte. New result fields are `data.outputs` and `data.realms`, with the artifacts `map-world-outputs.json` and `map-world-realms.json`. Realms grow by weight from their capitals, seeds and claims; borders along rivers and ranges for realms come with the territory service in a later release. See the [changelog](https://github.com/klimPaskov/hoi4-agent-tools/blob/v4.5.0/CHANGELOG.md), the [map guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/v4.5.0/docs/map.md#countries-the-mod-already-owns) and ADR 0069.
