# HOI4 Agent Tools 4.0.1

This release improves large-mod previews and cleans up temporary test files.

## What changed

- Temporary test folders are now removed after each test and when the process exits, and old scratch folders are cleaned up on startup. Tests in the held world-generation work could leave about 1 GB per run in the temporary directory; reference lookups in the released MCP do not copy source trees there.
- A background worker that stops without an answer now reports why, such as running out of memory, instead of always suggesting that memory ran out. Workers also get a larger memory limit on machines that have the memory to spare, and GUI previews are drawn one at a time to keep peak memory lower.
- The politics preview chooses faction and balance-of-power panels from the declared country. Button labels written in lower case, such as the trade window's sort buttons, show their text instead of the raw key. 16-bit DDS portraits are drawn.
- Font atlases keep the named font's colours, so super-event descriptions use their declared dark text instead of falling back to white.

## Qualification and limits

The chemical folder, super-event window and division designer rendered on the full external mod. The chemical preview matched 3.10.0 and installed 4.0.0; the earlier worker crash could not be reproduced, so its cause remains unconfirmed.

The broad installed-game suite passed 60 checks, including its MCP calls, fonts and native GUI checks. Three direct-analysis assertions still fail: an automatically chosen GUI example has no shown sprites, unrestricted event analysis reaches its ten-million-step work limit, and the technology test expects full analysis instead of the focused analysis used for installed-game sources since 3.10.0. Use a named GUI window and narrow event selectors. Engine-provided text still needs scenario values when no localisation definition supplies it.

## Get started

```bash
npm install --global hoi4-agent-tools@4.0.1
hoi4-agent-tools-setup --print-client-config
```

See the [setup guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/main/docs/setup.md) for game and mod paths.
