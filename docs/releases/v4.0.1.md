# HOI4 Agent Tools 4.0.1

This release fixes disk and memory problems found while using 4.0.0 on a very large mod.

## What changed

- Temporary test folders are now removed after each test and when the process exits, and old scratch folders are cleaned up on startup. Earlier builds could leave about 1 GB per run in the temporary directory.
- A background worker that stops without an answer now reports why, such as running out of memory, instead of always suggesting that memory ran out. Workers also get a larger memory limit on machines that have the memory to spare, and GUI previews are drawn one at a time to keep peak memory lower.
- GUI previews of the national focus, trade and politics windows follow what the game shows for the chosen country. Button labels written in lower case, such as the trade window's sort buttons, show their text instead of the raw key. 16-bit DDS portraits are drawn.

## Get started

```bash
npm install --global hoi4-agent-tools@4.0.1
hoi4-agent-tools-setup --print-client-config
```

See the [setup guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/main/docs/setup.md) for game and mod paths.
