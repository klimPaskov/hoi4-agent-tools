# HOI4 Agent Tools 4.0.4

This patch reduces the work needed to preview one GUI window or technology folder in a large mod.

GUI previews avoid redundant symbol indexes, restrict asset fallback to asset roots, and load flags for declared countries instead of every country. Condition definitions are reused across states. Technology folders use one cached source index and leave inbound-reference analysis to `hoi4.tech_inspect`.

Progress identifies the current rendering phase, and deadline errors include the last phase. Localisation resolves nested `$KEY$` references across files with bounded cycle handling. Numeric global flags now work consistently for both super-event visibility and text selection. Supplied GUI scenarios are preserved; request `generatedScenarios` explicitly for exploratory values and visibility.

The existing 16-bit DDS, declared font-colour, hidden-widget and timed sprite-frame support remains covered by regression tests. PNGs represent the requested `animationTimeSeconds`; they are not animated files. Engine-only labels, lists and numeric values require scenario facts and remain unresolved when those facts are absent.

## Get started

```bash
npm install --global hoi4-agent-tools@4.0.4
hoi4-agent-tools-setup --print-client-config
```

Public tool schemas are unchanged. See the [GUI guide](https://github.com/klimPaskov/hoi4-agent-tools/blob/v4.0.4/docs/gui.md) for a focused preview and the [architecture decision](https://github.com/klimPaskov/hoi4-agent-tools/blob/v4.0.4/docs/adr/0050-scoped-render-source-work.md) for source-scope and cache details.
