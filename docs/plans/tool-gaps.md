# Tool gaps log

A running log of gaps found while using the tools on large mods. Add one row per gap when it is found; change its status when work starts or ends and never delete a row. Status is `open` (no work planned), `planned` (a change is designed), `in progress`, or `fixed` (with the release). Fixes name the architecture decision (`docs/adr`) that implements them where one exists. The map rows were found on 2026-10-19 while diagnosing a generated total-conversion map.
