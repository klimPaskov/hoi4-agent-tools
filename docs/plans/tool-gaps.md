# Tool gaps log

A running log of gaps found while using the tools on the ZIN program. Add one row per gap when it is found; change its status when work starts or ends and never delete a row. Status is `open` (no work planned), `planned` (a change is designed, with its section), `in progress`, or `fixed` (with the release). The map rows were found on 2026-10-19 while diagnosing the ZIN map; their designs are in [zin-map-pipeline.md](zin-map-pipeline.md), where `C1` to `C15` name the tool changes.
