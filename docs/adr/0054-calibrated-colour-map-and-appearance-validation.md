# ADR 0054: Calibrated colour map, graphical terrain rules and appearance validation

## Context

The terrain shader overlays the colour map on the atlas texture at strength 0.75 in gamma space (`GetOverlay(diffuse, colormap, 0.75)`): channels below 0.5 darken, channels above 0.5 lighten. The base game's land colour map is dark and varied (mean value 74, 1,084 distinct 5-bit colours). The generator wrote ten flat tints at 1.45 to 1.75 times that brightness, so the map rendered pale: on the ZIN map the mean value is 129 and there are 14 distinct colours. Permanent-snow terrain was tinted as plains, and only 12 of the base game's 22 land indices could be written. Validation never read the bitmaps, so "offline validation passes" while terrain, rivers, trees, colour maps and normals were wrong.

## Decision

Stage A (this ADR) works on today's inputs. `create_world.colormap.profile` is `legacy` (the original flat tints, byte-stable) or `calibrated`; `look` (`vanilla-temperate`, `fertile`, `arid`, `custom`) selects a palette set and implies `calibrated`. `custom` requires `colormap.palette`, which overrides the intended colour map value of any class; combining `look` with `profile: legacy` is refused. Without either field the profile is `legacy`, so existing requests keep their colour maps.

The calibrated map starts from the base game's measured class means (plains 68,68,41; forest 47,55,24; hills 64,66,36; desert 118,98,64; mountain 59,60,35; marsh 51,55,30; jungle 36,51,16; permanent snow 55,58,35; farmland 76,74,42; urban 69,73,43). Each pixel's colour is the class colour times a factor from two octaves of deterministic value noise, a hillshade term from the heightmap, a slow hue drift, a wetness shift (wet ground greener, dry warmer) and per-channel jitter. The sea floor and lakes use the base game's nearly uniform blue values. The city-light mask stays in the alpha channel. Only `+ - * /` and integer hashes are used, so output is identical on every platform.

Graphical terrain is chosen by rule when the profile is `calibrated`: farmland (index 5) on wet, flat plains; sparse forest (index 4) where low-frequency noise thins a forest; grassy mountain (index 20) on wet mountain ground. A variant is used only when the active `common/terrain` files still define that index for that category and draw a tile; without terrain files the base game's numbering is assumed. Permanent snow keeps its indices (19 and 16) and now has its own colour class. Stage B, an inverse solver that chooses colour map values from target albedo, follows with the climate fields (plan C8).

Appearance validation (`map/appearance-validation.ts`) reads each file in row strips, yields between strips, and examines only files present in the scanned set. A scan for `map_inspect` includes the mod's own bitmaps and colour maps; a world being created validates its proposed files. The codes are `MAP_RIVER_*` (format, size, palette header, index range, 2 x 2 blocks, orthogonality, sources, sea pixels, density), `MAP_TERRAIN_BITMAP_*`, `MAP_HEIGHT_*`, `MAP_TREES_*`, `MAP_COLORMAP_*` (size, range, city-light alpha), `MAP_NORMAL_*` (size, unit length, response to relief) and `MAP_CITIES_*`. Water and edge codes are in ADR 0053 and ADR 0061. A format or size defect is an error; a statistical deviation is a warning. Every threshold was run against the installed base game and set so it raises no error: for example 4 river blocks among 90,000 river pixels, 53 undefined terrain pixels among 11.5 million, or 10% of normals off unit length are warnings or ignored, while a defect that covers a whole lake or river is an error. `MAP_COLORMAP_RANGE` warns when the land mean value leaves 50 to 100, the number of distinct 5-bit colours falls below 400 (scaled down for small maps), or the value deviation is under 15.

## Consequences

Old requests keep their colour map until the caller opts in. The model of the overlay ignores lighting, fog and the snow layer, so the offline numbers approximate the look; screenshots from the owner calibrate the tables. The `look` palettes are heuristic multipliers of the base game's table and are expected to change with the biome work. Rules that the plan listed but the files cannot decide are not implemented: widths that never narrow downstream need a flow direction, and "known mesh indices" of `trees.bmp` is checked as "inside the declared palette".

Regressions: table and look tests, statistics of the calibrated map (range, distinct colours, deviation), determinism, legacy byte equality, snow tint, terrain variants with and without declared entries, one clean fixture and one fixture per defect for each validator (2 x 2 river block, second source, a missing source, wrong size, undefined index, texture 255), a flat-colour-map warning, a size mismatch that blocks the write, and a 4,096 x 2,048 run that stays bounded.
