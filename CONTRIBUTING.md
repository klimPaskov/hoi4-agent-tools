# Contributing

Contributions are welcome through issues and pull requests.

1. Discuss material public-schema or architecture changes in an issue first.
2. Install the supported Node.js version and run `npm ci`.
3. Make a focused change with tests and documentation.
4. Add a changelog entry as a new file under `changelog.d/`; do not edit `## Unreleased` in `CHANGELOG.md` (see [changelog.d/README.md](changelog.d/README.md)).
5. Run `npm run check`.
6. Confirm no installed-game or third-party-mod content is included.

See [Development](docs/development.md) for project commands. Security-sensitive reports belong in private vulnerability reporting as described in [SECURITY.md](SECURITY.md).

By contributing, you agree that your contribution is licensed under Apache-2.0.
