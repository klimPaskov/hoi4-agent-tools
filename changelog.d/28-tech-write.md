- New tool `hoi4.tech_write` (issue 160, first part): add, replace or remove one technology of a mod `common/technologies/*.txt` file, touching only that block. The `@name = value` variable lines, comments, the other technologies, newline style and encoding come back as they were, and the preview shows the change with three lines of context. `add` takes the text between the braces and goes at the end of the `technologies` block, or into a new file with `file` and `createFile: true`; `replace` is also how a technology is moved in the tree (a new `folder` position, `path`, `research_cost` or `start_year`), and `remove` deletes it. A technology that only the game files define, a duplicate id, a body that is not one balanced block and a layout the edit cannot place safely are refused with the reason. The preview warns about missing English text for the id and `<id>_desc`, an undefined icon sprite, a tree folder nothing defines, and unlocked equipment, modules or sub-units that do not exist; an apply that names a folder nothing defines is refused by the post-write check, which now also scans the folder, unit and building definitions a technology refers to. Overlap and unreachable-technology checks, and doctrines, follow.
