- The Rust engine is laid out for porting the server in parallel (ADR 0091, a step of ADR 0089). Sixteen new crates hold the pieces still to move: the core contract, the atomic rewrite engine, artifacts and diffs, jobs, the analyzers, the writers, GUI, map, reference search and the MCP transport. `hoi4-engine serve` now dispatches through an operation registry each crate fills, and refuses to start when an operation name is registered twice or shadows a built-in one. `hoi4-core` holds the diagnostic, canonical JSON (byte-equal to the TypeScript server), scanned-file and rewrite-plan types. Writers return a plan and never write files themselves. The server calls registered operations through one schema-checked helper, which reports a missing engine or operation as `ENGINE_UNAVAILABLE` and passes an operation's own refusal code through. No tool changes its behavior.
