- New tool `hoi4.doctrine_write` (issue 160, doctrines): add, replace or remove one grand doctrine, track or subdoctrine of a mod `common/doctrines` file, touching only that block. Other doctrines, comments, newline style and encoding come back as they were, and the preview shows the change with three lines of context. `add` takes `kind` (`grand_doctrine`, `track` or `subdoctrine`, which decides the folder) unless `file` says where, and the text between the braces; it appends to the mod's only file of that kind, or to a new file with `file` and `createFile: true`. `replace` and `remove` find the doctrine by id in the mod and need no kind. A doctrine that only the game files define, a duplicate id, a file of another kind than the one asked for, a body that is not one balanced block and a file with syntax errors are refused with the reason. It warns, and still writes, when the doctrine's `name` has no English text, its `icon` sprite or `folder` is not defined, or a track it lists does not exist.
