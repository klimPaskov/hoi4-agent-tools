- `hoi4.event_inspect` with `mode: "compare"` and a `proposedSources` overlay no longer fails to finish on a large graph (issue 206). An event trace rebuilt the index of all graph nodes for every node it visited, so the full-graph reachability pass of a comparison took time quadratic in the graph, and its depth layers were built by scanning every node once per depth level. On a three-event mod plus the installed game (about 7,000 events) the comparison did not finish in ten minutes and once ended the server; it now takes about 33 s, of which the scan is 15 s. A walk over 20,000 chained events takes 0.1 s instead of 13 s, and a regression test holds it under 5 s.
