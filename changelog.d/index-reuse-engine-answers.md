- The shared symbol index no longer sends every scanned file to the engine on each rebuild. An unchanged installed-game file keeps the engine's answer from the previous build, so after a mod edit only the edited files are indexed again, and the final grouping of the index skips the work for the many symbols that have a single definition. On a small mod with the game a rebuild takes about 130 ms instead of about 750 ms, and a changed focus rewrite answers about a second sooner (issue 137).
