- Answer every `hoi4.source_lookup` call that names a symbol from the shared Rust engine, references included (ADR 0083, maintainer decision M-8, issue 107). The engine ports the definition walk's technology, focus, GUI and state references and the semantic scan's typed script edges, keeps those to the requested symbol, and counts the rest, so `referenceCount`, `referencesComplete` and `unresolvedReferenceCount` stay the whole scan's. The answer is the TypeScript route's, checked by `scripts/source-lookup-parity.ts` on the installed game and the benchmark mods. Only a request for a source position (`path` and `line`) still scans in TypeScript. A missing engine is `ENGINE_UNAVAILABLE` for every lookup that names a symbol, `includeReferences` included.
