- `hoi4.event_write` can now report what an edit does to the event chains (issue 159): pass `chain: true` and the result carries a `chain` report with the events the edit adds, removes or changes, the changed options, the calls it adds and removes, the events that lose a caller, the issues it introduces or resolves (`EVENT_OPTION_DANGLING` for an option left firing nothing, for example) and the events no root reaches any more. It compares the event graph of the mod and the game with one in which the planned file replaces the old one, so it needs a scan of both, about 15 s on the installed game, and is off by default. A comparison that cannot run is reported as `computed: false` with the reason and a warning, and the write itself is not affected.
