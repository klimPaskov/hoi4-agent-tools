- Add `hoi4.idea_write` (issue 158): add, replace or remove one idea (national spirit, law or advisor idea) in a mod `common/ideas` file in one call. It changes only that block: comments, neighbouring ideas, line endings and the byte order mark come back byte for byte, and the result is parsed again and refused if it has syntax errors or touched another definition. `add` needs `category` and `body` (the text between the braces) and refuses a duplicate id, an unknown category (it lists the categories the file has) or a body that is not one block; `replace` and `remove` find the idea in the mod, and refuse one that only the game defines. `apply: false` returns the diff; `apply: true` writes it as one journaled transaction. A missing English localisation key or picture sprite is a warning, not a refusal. It is in the `advanced` profile. New categories, new files and characters follow.
