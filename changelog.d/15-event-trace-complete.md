- A focused `hoi4.event_inspect` trace or path that answers its question is now `EVENT_INSPECTED`, not `EVENT_INSPECTED_PARTIAL` (issue 66, ADR 0085). The partial code was set for every trace and path on every workspace, because the focused analysis defers the whole-workspace helper and lifecycle passes, so an agent could not tell a complete 7-node trace from a cut one. A trace cut by a limit, with a node on its boundary or with a skipped source, stays partial and says where (`summary.trace.truncated`, `boundaryNodes`). The rule is: a result is partial only when something the answer needs is missing.
