- An idle stdio server no longer loads or recovers any workspace (issues 292 and 296). Since the handshake fix it still loaded every mod and recovered every workspace's journals in the background right after `initialize`, which is why idle servers held 386 to 669 MB of private memory with a configuration, against about 110 MB without one. Now `initialize`, `tools/list` and `prompts/list` start nothing. The first tool call, resource read or other request that needs a workspace loads the workspaces, and each workspace's interrupted rewrite is recovered once on that workspace's first use: before its first file access through the resolver, before its first job is submitted and before its first rewrite is planned or applied. A failed recovery is still recorded with the `transaction_recovery_blocked` event, reads go on, and rewrites of that workspace are refused with `TRANSACTION_RECOVERY_REQUIRED`, as before. Releasing a workspace's caches after an idle period is not part of this change and stays with issue 296.
