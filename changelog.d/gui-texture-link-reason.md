- GUI previews say why a texture behind a linked folder is missing (issue 218). The scanner never follows a symbolic link or a Windows junction inside a workspace, so a mod copy whose `gfx/` was a junction into the real mod lost every texture, and `hoi4.gui_render` reported each one as `GUI_TEXTURE_UNSUPPORTED` "Texture not found", which a modder read as an unsupported DDS format. The message now names the link and says links are not followed (for example "gfx in the mod folder is a symbolic link or junction"), for `hoi4.gui_render`, `hoi4.gui_inspect` and the preview of `hoi4.gui_rewrite`. Links are still not followed. Troubleshooting has a section on linked folders.
