- The artifact store, unified and binary diffs, the changed-files summary, managed output inventories, the offline PNG comparison and the scratch-directory sweep now exist in the Rust engine (`hoi4-artifacts`, packet P3 of ADR 0089), reachable as the `artifacts.*` and `diff.*` operations. Store layout, names, manifests, URIs, limits, pruning and error codes are the TypeScript ones, so both servers read each other's stores. The text diff is byte-equal to the TypeScript one. The managed-output planner takes its path predicates as data (`PathRule`) instead of functions. The Node server does not call them yet.
- The minimum Rust version of the engine workspace is now 1.89, for std `File::lock` (the artifact publish lock). The pinned toolchain stays 1.97.1.
