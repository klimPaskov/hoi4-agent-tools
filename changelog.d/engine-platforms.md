- Say what is missing and how to get it when no `hoi4-engine` binary is found. The package ships the engine for Windows x64, Linux x64 and arm64, and macOS on Apple silicon; on another platform, such as an Intel Mac (`darwin-x64`), a tool that needs it answers `ENGINE_UNAVAILABLE` naming the shipped platforms and how to build the engine and point `HOI4_ENGINE` at it, and on a shipped platform whose binary is missing it says to reinstall. The README names the supported platforms.
