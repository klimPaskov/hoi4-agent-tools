- Map tools pass the province raster request and answer to `hoi4-engine map-provinces` through temporary files (`--input`, `--output`) instead of the engine's stdin and stdout. On macOS runners the synchronous call, which wrote hundreds of kilobytes to the pipe and read as much back, sometimes hung until its 120-second timeout and failed the map tests with `ENGINE_UNAVAILABLE` (`spawnSync ... ETIMEDOUT`). The engine still reads stdin and writes stdout when the options are absent.
