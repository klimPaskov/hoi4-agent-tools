- Build the shared symbol index on the Rust engine and retire the TypeScript index (ADR 0085, maintainer decision M-8, step 5). The events, technology, decisions, focus, GUI, impact, package check, mechanics and scenario tools read their definitions, metadata, locations, references and diagnostics from `hoi4-engine index-files`. The engine parses and walks the files, and the server keeps the cross-file rules (load order, shadowing, collisions, unresolved references, ceilings). Over the same files the result is the TypeScript index's, record for record. This was checked on the installed game and the six benchmark mods, 3.07 million definitions with every reference and diagnostic. On Chaos Redux the index took 2.8 to 5.2 s instead of 26 s for the TypeScript scan and index, and on the game 1.1 s instead of 7.6 s. The persistent analysis cache (`analysis-cache/` under the server state root) is retired with it, because the TypeScript index was what filled it. Tools that build the index answer `ENGINE_UNAVAILABLE` without an engine.
