- The world output record (`.hoi4-agent-world.json`) now lists the files later map edits create (issue 182). Since 4.16.0 every map edit refreshed the record, but only the entries it already listed: a state file that a later `create_state`, split, merge or territory edit wrote (`history/states/<id>-AGENT_STATE.txt`), and other new world outputs such as `world_l_english.yml`, were never added. A copy synced from the record then loaded without those states, and the game crashed. `record_world_outputs` walked the same listed entries and reported them all matching. Now every map edit adds the world outputs it creates, and `record_world_outputs` adds every world output of the mod the record does not list; both report the added paths (`added`, `addedPaths`). Run `record_world_outputs` once on a mod written before this release to repair its record.
