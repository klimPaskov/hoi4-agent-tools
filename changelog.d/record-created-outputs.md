- Add the files map operations create to the world output record (`.hoi4-agent-world.json`). `assign_territory`, `split_state`, `create_state` and the other operations created state and strategic-region files that never entered the record, so a sync that copies the recorded files left them out. ZIN's first Linux run of a redrawn map lost 124 state files this way, and the game stopped at setup. Every map rewrite now also adds each file it creates where the world keeps its outputs (state files, strategic regions, map files and world localisation, not country files), in the same transaction. `MAP_WORLD_OUTPUTS_REFRESHED` gives `added` and `addedPaths`. For mods already in this state, `record_world_outputs` takes `adoptUnrecorded: true`, which also adds the mod's files at those paths that the record lacks.
