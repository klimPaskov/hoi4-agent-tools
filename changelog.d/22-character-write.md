- New tool `hoi4.character_write` (issue 158): add, replace or remove one character of a mod `common/characters/*.txt` file, touching only that block. Every other byte of the file, its comments, neighbours, newline style and encoding, comes back as it was, and the result lists how many other characters were checked to be unchanged. `add` needs `body` (the text between the braces) and goes at the end of the file's `characters` block, or into a new file with `file` and `createFile: true`; `replace` and `remove` find the character by id in the mod's files. `apply: false` returns the diff and writes nothing. It warns, and still writes, when the character's `name` key has no English text or a portrait sprite is not defined. A character that only the game files define is refused with the reason, as are a duplicate id, a body that is not one balanced block, and a file layout the edit cannot place safely. `idea_write` and `character_write` now share their indentation helpers.
