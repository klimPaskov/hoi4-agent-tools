- Event Chain Viewer analysis spends far less time hashing (maintainer decision M-8, issue 69). A CPU profile of `hoi4.event_inspect` `state_flow` on Chaos Redux (141 s) showed about 60 s of canonical JSON hashing and 22 s of garbage collection. Two causes are fixed. A dependency-walk checkpoint ran `z.json()` over the walk's whole frontier before every save (25 s) and canonicalised it twice. It now checks only the key and revision, and canonical JSON still refuses what JSON cannot hold. Loading a checkpoint still validates all of it. The semantic graph hash serialised each edge and state access with its option's conditions inline, about 3 GB on Chaos Redux (264,828 edges of 9.5 KB on average). Each shared condition is now hashed once and named by its digest (`event-semantic-graph-hash.v3`). `graphHash` values therefore differ from earlier versions, but within one version they still change exactly when the graph's meaning does. On the benchmark machine the Chaos Redux `state_flow` case took 79 and 70 s instead of 107 and 111 s.
