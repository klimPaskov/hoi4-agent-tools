- Map validation (the checks before and after every map rewrite, and the map validation itself) now runs on the shared Rust engine (`hoi4-map`, ADR 0089 step 6). The engine reads each scanned file by path and refuses one whose size or SHA-256 changed since the scan, and a map whose in-memory files exceed one request is refused with `MAP_ENGINE_PAYLOAD_LIMIT` instead of being validated in part. On seven large maps the findings, their order, `passed` and every check match the earlier TypeScript checks exactly. Building and position records have their own 2,000,000-record ceiling, so a mod with very large position tables is no longer refused (issue 172).
