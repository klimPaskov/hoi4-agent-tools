- The Rust `hoi4-event` crate gains the event analysis as engine operations: `event.fragments` (one source file to its nodes, edges, state accesses and findings), `event.graph` (the fragments to the semantic graph with helper projections, state links and findings) and the graph algorithms `event.trace`, `event.path`, `event.components` and `event.reachable`. The TypeScript server does not call them yet, so no tool changes behavior. A parity script (`scripts/event-parity.ts`) compares each operation with the TypeScript implementation.
