- The Rust `hoi4-event` crate gains the event analysis as engine operations: `event.fragments` (source files to their nodes, edges, state accesses and findings), `event.graph` (the semantic graph with helper projections, state links and findings, built from fragments or straight from files the engine reads itself by path and refuses when they changed since the scan) and the graph algorithms `event.trace`, `event.path`, `event.components` and `event.reachable`. The TypeScript server does not call them yet, so no tool changes behavior. A parity script (`scripts/event-parity.ts`) compares each operation with the TypeScript implementation.
