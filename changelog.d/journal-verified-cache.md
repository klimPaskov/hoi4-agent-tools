- A rewrite no longer gets slower with every earlier rewrite of the session (issue 137). Each rewrite first prunes expired journals, and that loaded every retained journal (up to 128, kept for an hour) and parsed, schema-checked, authenticated and integrity-hashed each one again, so in a long editing session the journals took more of each call. A journal whose exact bytes the server already verified, under the same workspace roots, is now reused; any change to its bytes is verified in full as before, and the check against the server state's journal head still runs on every load.
