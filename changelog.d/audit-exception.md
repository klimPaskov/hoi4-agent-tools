- CI and the release workflows now audit dependencies in two steps. The audit of what users install (`npm audit --omit=dev --audit-level=high`) stays strict. A full audit that includes development tools (`npm run audit:gate`) fails on every high or critical advisory except one listed in `scripts/audit-exceptions.json`, for its exact package, with a reason and a review date. The gate also fails once a review date passes, or when an exception no longer matches any advisory. The first exception is GHSA-fc5q-39xc-vjpf in picomatch: it reaches only test and lint tools, and no fixed version is published yet. Nothing changes in the published package.
