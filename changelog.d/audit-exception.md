- CI and the release workflows now audit dependencies in two steps (ADR 0088). The audit of what users install (`npm audit --omit=dev --audit-level=high`) stays strict, with no exceptions. A full audit that includes development tools (`npm run audit:gate`) fails on every high or critical advisory except one listed in `scripts/audit-exceptions.json`, for its exact package, with a reason and a review date. A listed advisory still fails the gate when it reaches the production dependencies, when the package has published a fixed version, when the review date has passed, or when the entry no longer matches any advisory. The list starts empty. The first entry, GHSA-fc5q-39xc-vjpf in picomatch, was removed when GitHub withdrew that advisory on 2026-11-18; the gate flagged the stale entry as designed. Nothing changes in the published package.
