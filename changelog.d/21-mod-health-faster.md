- `hoi4.mod_health` is faster on large mods (issue 69). Checking a script file used to scan the whole workspace again, which cost about a second per file on a mod with eight thousand files, so the 30 second budget reached only about 35 files. The call now scans once and builds the identifier, scripted effect and trigger sets once, so 400 files are checked in about 18 s. The engine audits run one after the other, quick ones first, with the whole-mod check beside them, instead of four at once, and the script check lets them deliver their output between files. On Old World Blues with a warm file cache the call went from 38 s (37 files checked) to 18 s (400 files). The note on a partial script check now says whether the time budget or the 400 file limit stopped it.
