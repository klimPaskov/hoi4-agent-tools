- Add `closure: true` to `hoi4.script_validate`, on the shared engine (ADR 0083, issue 107). It counts the references of the mod's own sources that resolve, do not resolve, or cannot be decided, per target kind, and returns a verdict: `incomplete` whenever anything is unknown or the scan is partial, `unresolved` when only unresolved references remain, `closed` otherwise. Dynamic targets, kinds a skipped source could define, and variables, flags and event targets that are read but never written in the scanned sources count as unknown. The option excludes `source` and `path`; the result has `checksPerformed: ["closure"]`, a `closure` object, and no `documentation`, which is now optional in the output schema.
