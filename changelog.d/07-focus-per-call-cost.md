- Make `hoi4.focus_inspect` and `hoi4.focus_rewrite` far cheaper per call (issue 137). On a four-focus mod with the game installed a warm inspect took 20 to 30 s; it now takes about 2 s on a loaded machine. The importer rebuilt a set of every game identifier for each assignment of every focus, the reference catalog was rebuilt for each imported file, a call that named a tree but no file imported every focus file of the game, and every rewrite and the next inspect indexed the whole game again. Each is fixed (the catalog sets and the catalog are cached, a tree id reads only the files that define it, and the workspace's last index supplies the records of unchanged files after an edit). A call with a tree id and no file now lists only that tree's source files in its source hashes.
