- Answer plain-word documentation questions better, and show ten candidates (issue 64). Every one of the 1,127 documented effects and triggers now has ten plain-word phrasings in `command-phrases.json` instead of four, written once at build time and shipped as data. `hoi4.reference_search` returns up to ten hits by default, and a command hit carries a one-line meaning with the scopes it works in, so an agent can pick the right one. On a new blind set of 43 questions the right answer is first on 31 (was 23) and among the first ten on 39 (91 percent, was 36). Counting a hit by command instead of by documentation file corrects the earlier figures of this issue upward.
