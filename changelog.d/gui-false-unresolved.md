- Fixed `hoi4.gui_inspect` and `hoi4.gui_render` reporting false unresolved references: a sprite or font of another window in the inspected window's `.gui` file, or one a kept script names, now resolves from its `.gfx` file in the game or the mod instead of being reported as missing because that file was left out of the window graph, and a static GUI text that is not in the form of a localisation key (such as `Title text here!` or `--`) is drawn as written, as the game does, instead of being reported as a missing key. A missing sprite and a missing key in key form are still reported.
