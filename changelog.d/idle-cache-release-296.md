- The idle release of a server's in-memory analysis caches is now a setting, `idleCacheReleaseSeconds` (issue 296). The scan, index and view caches were already released 30 s after the last tool call, but the 30 s was fixed and undocumented. The default stays 30; `0` releases the caches as soon as a call ends, and the maximum is 3,600. It is listed in the configuration table and in `configuration.schema.json`.
