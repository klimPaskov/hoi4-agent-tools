- Give the states a map write creates or reshapes their state-level building positions (issue 193). `create_state`, `split_state` and `assign_territory` with the province unit wrote no state-level lines in `map/buildings.txt` for the states they created or reshaped, because the `follow-province` distribution moves only province lines. ZIN's game then reported a missing air base, rocket site or gun emplacement for 139 states. A write now adds the lines such a state lacks, placed as `regenerate_map_positions` with mode `missing` places them, and reports `MAP_STATE_BUILDING_POSITIONS_ADDED`. A building type counts as state-level when every state had a line for it before the write. Existing lines are never moved, and unchanged states are left alone.
