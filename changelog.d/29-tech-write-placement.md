- `hoi4.tech_write` can now report what an edit does to the technology trees (issue 160): pass `placement: true` and the result carries a `placement` report with the technologies the edit adds, removes, moves (from and to folder and coordinate) or changes, the prerequisite paths it adds or removes, the issues it introduces or resolves (`TECH_FOLDER_COORDINATE_OVERLAP` when two technologies of one branch land on one coordinate, for example) and the technologies it leaves unreachable or reachable. It compares the technology graph of the mod and the game with one in which the planned file replaces the old one, so it needs a scan of both, about 20 s on the installed game, and is off by default. A comparison that cannot run is reported as `computed: false` with the reason and a warning, and the write itself is not affected.
