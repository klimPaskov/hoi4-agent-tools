- A focused `hoi4.event_inspect` trace or path no longer fails its `validation.passed` because of blocking diagnostics in unrelated files (issue 66, ADR 0086). It counts those in the files of the events it covers and names how many sit elsewhere in the workspace in the check message, so a clean `news.1` trace in vanilla is not reported as failing for two unrelated diagnostics. Every other event answer still counts the whole workspace.
